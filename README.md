# Neeraj Gupta portfolio

A responsive, static portfolio with four case studies, an interactive component concept, career history, and contact links.

## Files

- `dist/index.html` — page content and metadata
- `dist/styles.css` — visual system and responsive layouts
- `dist/app.js` — demo interactions and case study content
- `.openai/hosting.json` — Sites project identity and static output configuration

Serve `dist/` with any static web server. No dependency installation or build is required.

## Content notes

Resume-based facts belong to Neeraj Gupta. The booking demo and component illustrations are portfolio concepts, not employer screenshots. No live booking or external form submission occurs. There is no analytics, contact-form backend, or visitor data storage.

Google Fonts supplies Manrope. A system sans-serif fallback remains available if the font cannot load.

The Sites deployment starts private. The resume link points to Neeraj's improved Google Doc and retains that document's existing sharing permissions.
